# chiaki-tizen 0.2.0

This release focuses on making chiaki-tizen easier to diagnose on real TVs,
more tolerant of home-network changes, and much closer to over-the-internet
Remote Play through PSN signaling.

## Highlights

- Added an in-app debug report flow for TV troubleshooting.
- Added experimental PSN Remote Play login and signaling support.
- Improved console discovery so saved profiles can recover after a PlayStation
  changes IP address.
- Reduced console-list UI latency on Samsung TVs, especially older models.
- Added a dedicated chiaki-tizen logo to the console-select screen.

## New

### Debug Reports

You can now generate a redacted debug report directly from the app.

- Press the Blue remote key to open the on-screen debug log.
- Use Settings > Send debug report from the normal UI.
- Reports redact IP addresses and token-like strings.
- If the TV cannot open a share or issue flow, the report remains visible on
  screen so it can still be copied or photographed.

The report includes app state, stream settings, local storage summary, recent
diagnostic logs, and available Tizen system information. This should make TV
specific startup, network, and media issues much easier to investigate.

### Reset Saved Data

Settings now includes Reset saved data. Press it twice to clear saved consoles,
pairing keys, PSN login data, and stream settings.

This is useful when reinstalling builds through tools or package IDs that cause
Samsung TVs to preserve web storage across uninstall and reinstall.

### Experimental PSN Remote Play Support

0.2.0 adds a much more complete over-the-internet Remote Play path:

- Sony Remote Play OAuth login helper in Settings.
- Access and refresh token storage.
- PSN Account ID derivation from the login response.
- Console device ID lookup and caching through the PSN device list.
- Remote Play session creation.
- Authenticated push WebSocket setup.
- STUN candidate gathering.
- UDP hole-punch candidate checks.
- Remote session startup through chiaki's holepunch session path.

This is still experimental. Local-network Remote Play remains the supported,
known-good path. The internet Remote Play flow has the major code paths wired,
but real PSN behavior, Tizen socket behavior, and PS5 handshakes still need
on-device validation.

## Improvements

- Saved paired consoles now try to relink automatically when the console's IP
  address changes.
- Discovery uses the console host ID when available, with a conservative
  single-candidate fallback for older saved profiles.
- Console-list rendering is debounced and preserves focus across updates, which
  should reduce distracting jumps while discovery is active.
- The app automatically enables a lighter performance UI on unknown or pre-2024
  Samsung TV models, while keeping richer effects on confidently detected 2024+
  sets.
- Settings now uses TV-friendly custom select controls instead of relying only
  on native browser select behavior.
- Startup status text is quieter during normal boot and only surfaces splash
  status for actual module failures.
- More media and FEC diagnostics are logged for Tizen 9 video debugging.
- Video timestamps now account for reported lost frames, which should reduce
  audio/video drift after packet loss.

## Packaging And Build Notes

- Added WARP access grants for Sony Remote Play and QR-code helper endpoints.
- Added Tizen AIA-without-curl compatibility patching.
- Added a small AIA stub used by the WASM build.
- Expanded Tizen compatibility handling around sockets and errno behavior.
- The released Git tag is `v0.2.0`.

## Upgrade Notes

- Existing paired consoles should continue to work.
- If a saved console appears offline after your router changes its IP address,
  leave the console on and let discovery run; 0.2.0 can often relink it
  automatically.
- If the app behaves strangely after reinstalling, use Settings > Reset saved
  data and pair again.
- Internet Remote Play is experimental. For reliable play, keep using local
  network Remote Play.
